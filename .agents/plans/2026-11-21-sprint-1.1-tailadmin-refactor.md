# Kế Hoạch Triển Khai: Sprint 1.1 - Tích Hợp Theme & Bộ Thành Phần TailAdmin Vào Dự Án

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tích hợp toàn diện bộ Theme, Design Tokens, SVG Icons và Thư viện UI Components của TailAdmin vào ứng dụng Angular 22, thay thế lớp giao diện Prototype cũ trên toàn bộ các trang đang hoạt động thật, đảm bảo giữ vững 100% logic kiến trúc hiện có.

**Architecture:** Sử dụng Tailwind CSS với Dark Mode (`class`), kết hợp Angular Signals quản lý trạng thái giao diện trong `ThemeService`, xây dựng bộ thành phần dùng chung Standalone tuân thủ kỷ luật tương tác 8 trạng thái, sau đó refactor App Shell và lần lượt nâng cấp các feature screens mà không làm thay đổi các hợp đồng API hay state stores.

**Tech Stack:** Angular 22 (Standalone Components, Signals, OnPush), Tailwind CSS, PostCSS / Autoprefixer, TypeScript, Vitest, Playwright E2E.

**Spec:** [.agents/specs/2026-11-21-sprint-1.1-tailadmin-refactor-design.md](file:///c:/Workplaces/PROJECT/AgentCoreSystem/.agents/specs/2026-11-21-sprint-1.1-tailadmin-refactor-design.md)

## Global Constraints

- 100% Standalone Components với `ChangeDetectionStrategy.OnPush` và Angular Signals.
- C# & TS Files: Header bản quyền Phong Minh Dang `<dangminhphong912@gmail.com>`.
- Giữ nguyên 100% Backend .NET 9 API, không tạo mock ảo trong luồng thật (`RULE-04`), không tạo UI rỗng/chết (`RULE-05`).
- Xóa bỏ 100% emoji làm biểu tượng chính thức, chuyển đổi toàn bộ sang SVG icons theo phong cách TailAdmin.
- Hỗ trợ mượt mà cả 2 chế độ Dark Mode (`.dark`) và Light Mode trên mọi thành phần giao diện.

## Review Focus

1. **Dark Mode Flashing / Inversion**: Kiểm tra tình trạng nháy sáng hoặc mất độ tương phản chữ đen trên nền tối khi tải lại trang hoặc bấm chuyển đổi giao diện.
2. **Signal & Reactive Form Bindings**: Đảm bảo quá trình thay thế markup HTML trong Form Login, User Modal, Password Modal không làm mất các validation errors hoặc `formGroup` bindings.
3. **Responsive Mobile Drawer**: Kiểm tra Sidebar trên màn hình < 768px tự động ẩn thành drawer trượt ngang và đóng lại khi người dùng bấm vào backdrop hoặc chọn menu.
4. **Bảo toàn E2E Playwright Selectors**: Đảm bảo các data-attributes (`data-testid`), input names hoặc route links mà E2E tests đang nhắm tới không bị gãy vỡ.
5. **DRY & Dead Code Cleanup**: Dọn sạch các class SCSS prototype cũ không còn dùng trong `styles.scss` sau khi chuyển dịch sang Tailwind CSS.
