## 1. Bối Cảnh & Định Hướng Cốt Lõi (Core Intent)

Mục tiêu chính xác của **Sprint 1.1** là: **Tích hợp bộ Theme, Design Tokens và Hệ sinh thái Component của TailAdmin vào dự án Angular**, thay thế toàn bộ lớp áo Prototype tạm thời bằng giao diện quản trị chuyên nghiệp, sắc nét, hỗ trợ Dark/Light mode chuẩn mực.

Dự án tuyệt đối **không tự vẽ ra các tính năng giả tạo** (như biểu đồ Dashboard ảo, ma trận phân quyền giả, hay chức năng tìm kiếm rỗng) để tuân thủ triệt để quy tắc **Anti-AI-Slop** (`RULE-04` cấm mock trong luồng thật, `RULE-05` cấm tính năng rỗng). Thay vào đó, tập trung 100% vào việc:
1. Thiết lập hạ tầng Tailwind CSS + Dark/Light Theme.
2. Xây dựng bộ UI Components chuẩn TailAdmin (Buttons, Inputs, Cards, Badges, Modals, Tables, Dropdowns, SVG Icons).
3. Tái cấu trúc App Shell (`MainLayoutComponent`) chuẩn mẫu TailAdmin.
4. Áp bộ Theme & Component mới vào toàn bộ các trang đang hoạt động thật của hệ thống.

## 2. Phạm Vi Thực Hiện (Scope & Boundaries)

### 2.1. Nền Tảng Kỹ Thuật & Design System
- **Tailwind CSS Integration**: Tương thích hoàn toàn với `@angular/build` của Angular 22.
- **Theme Tokens**: Cấu hình `tailwind.config.js` chuẩn TailAdmin:
  - **Dark Mode**: Kích hoạt qua class `.dark` tại thẻ `<html>`.
  - **Colors**: Primary Blue (`#3C50E0` / `#465FFF`), Dark Canvas (`#1A222C`), Dark Card (`#24303F`), Light Canvas (`#F1F5F9`), Light Card (`#FFFFFF`), Border (`#E2E8F0` / `#2E3A47`).
- **`ThemeService`**: Angular Signal `currentTheme` (`'light' | 'dark'`), đồng bộ `localStorage` và `prefers-color-scheme`.
- **Hệ thống SVG Icons**: Thay thế 100% emoji bằng biểu tượng SVG chuyên nghiệp (Heroicons/Lucide) theo phong cách TailAdmin.

### 2.2. App Shell Layout (`MainLayoutComponent`)
- **Sidebar**:
  - Hỗ trợ mở rộng / thu gọn (Signal: `isSidebarCollapsed`).
  - Phân nhóm điều hướng theo cấu trúc thực tế:
    - **Tổng quan**: `/dashboard`
    - **Không gian làm việc**: `/organization` (Chứa Cây phòng ban, Kênh thảo luận, Kanban Tasks & Realtime Chat)
    - **Quản trị hệ thống**: `/system/users`, `/system/roles` (SuperAdmin/Admin), `/system/audit-logs` (SuperAdmin)
  - Responsive drawer cho màn hình Mobile/Tablet.
- **Topbar**:
  - Nút toggle Sidebar (Hamburger icon).
  - Nút chuyển Dark/Light mode tức thì.
  - Bộ chuyển đổi ngôn ngữ gọn gàng (`VI` / `EN`) đồng bộ `I18nService`.
  - Menu người dùng: Hiển thị Avatar (initials), Tên, Vai trò và nút Đăng xuất an toàn.

### 2.3. Bộ Thành Phần Dùng Chung (TailAdmin Shared Components)
- **`app-button`**: Chuẩn 8 trạng thái tương tác (`default`, `hover`, `active`, `focus-visible`, `disabled`, `loading`, `error`, `success`), các biến thể `primary`, `secondary`, `danger`, `outline`.
- **`app-card`**: Bề mặt TailAdmin với viền 1px tinh tế, tự động chuyển màu nền sáng/tối.
- **`app-badge`**: Các nhãn trạng thái ngữ cảnh (`success`, `warning`, `danger`, `info`, `neutral`).
- **`app-modal`**: Hộp thoại nổi có backdrop mờ, animation đóng/mở mượt mà, hỗ trợ phím `ESC`.
- **Form Controls**: Input text, Password input với nút ẩn/hiện mật khẩu, Select, Checkbox — chuẩn hóa theo style TailAdmin.
- **Data Table Styles**: Bảng dữ liệu chuẩn với header rõ ràng, hover effect trên hàng, phân trang và empty state.

### 2.4. Áp Dụng Theme Vào Các Trang Nghiệp Vụ Thực Tế
1. **Đăng nhập (`/auth/login`)**: Màn hình đăng nhập TailAdmin thanh lịch, hỗ trợ Dark/Light mode, tích hợp form reactive và hiển thị lỗi chuẩn RFC 7807.
2. **Dashboard Hiện Tại (`/dashboard`)**: Giữ nguyên vai trò trang tổng quan giới thiệu kiến trúc hệ thống hiện có, tái tạo lại bằng bộ thẻ Card và SVG icon của TailAdmin (tuyệt đối không thêm biểu đồ giả hay số liệu ảo).
3. **Không Gian Làm Việc (`/organization`)**: Áp dụng layout TailAdmin cho cấu trúc Cây phòng ban, Danh sách kênh, Bảng Kanban Tasks và Khung Chat Realtime. Giữ nguyên 100% Store, SignalR Hub và bảo toàn kết quả E2E tests.
4. **Quản Trị Người Dùng (`/system/users`)**: Bảng danh sách người dùng TailAdmin, thanh tìm kiếm, nút tạo mới và các modal Form/Đổi mật khẩu theo phong cách mới.
5. **Vai Trò & Nhật Ký (`/system/roles`, `/system/audit-logs`)**: Trình bày thông tin các vai trò hệ thống và cơ chế ghi log Hangfire/MongoDB dưới dạng Card/Table TailAdmin đồng bộ.

## 3. Ràng Buộc & Tiêu Chuẩn Bắt Buộc (Rules & Standards)

1. **Angular Standards**: 100% Standalone Components, `ChangeDetectionStrategy.OnPush`, Angular Signals, JSDoc header bản quyền Phong Minh Dang.
2. **Không sửa Backend**: Giữ nguyên 100% Backend .NET 9 API và DTOs.
3. **Anti-AI-Slop**:
   - `RULE-01`: Khớp contract FE $\leftrightarrow$ BE.
   - `RULE-04`: Không mock dữ liệu trong luồng thật.
   - `RULE-05`: Không đưa vào UI các nút bấm hay ô tìm kiếm chết/vô nghĩa.
   - `RULE-09`: Không nhân bản code, tái sử dụng các component dùng chung.

## 4. Kế Hoạch Triển Khai Tuần Tự (Implementation Phases)

1. **Phase 1: Nền tảng (Foundation)**
   - Cài đặt Tailwind CSS và cấu hình `tailwind.config.js`.
   - Tạo `ThemeService` (Signals cho Dark/Light mode).
   - Xây dựng component SVG Icon dùng chung.
2. **Phase 2: Bộ UI Components dùng chung (Shared UI Library)**
   - Xây dựng `AppButtonComponent`, `AppCardComponent`, `AppBadgeComponent`, `AppModalComponent`, Table & Form inputs styling.
3. **Phase 3: Tái thiết kế App Shell Layout**
   - Viết lại `MainLayoutComponent` (Sidebar collapsible, Topbar, Dark Mode toggle, Language switch, User profile).
4. **Phase 4: Hiện đại hóa các màn hình nghiệp vụ**
   - Refactor màn hình Auth Login.
   - Refactor Dashboard (thẻ thông tin kiến trúc theo style TailAdmin Card).
   - Refactor phân hệ System (Users, Roles, Audit Logs).
   - Refactor phân hệ Organization (Workspace Shell, Kanban Board, Chat Room).
5. **Phase 5: Kiểm thử & Nghiệm thu**
   - Kiểm tra Build (`npm run build`).
   - Kiểm tra Dark/Light mode toàn diện.
   - Chạy kiểm thử E2E Playwright (`npm run test:e2e`).
