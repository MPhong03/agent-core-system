## 1. Context & Problem Statement

Sau khi hoàn thành Sprint 1.1 tích hợp bộ theme TailAdmin, hệ thống đã vận hành ổn định trên nền tảng kỹ thuật mới (Tailwind CSS, Dark/Light Mode, hệ icon SVG, các component dùng chung). Tuy nhiên, trải nghiệm thị giác của người dùng chưa đạt chuẩn thẩm mỹ cao cấp do các vấn đề cốt lõi về **Bố cục (Layout)**, **Phần đệm (Padding)** và **Lề (Margin)** không đồng nhất:

1. **Card Padding bị dị biệt và bất đối xứng**:
   - Bảng dữ liệu Users dùng class TailAdmin cũ: `px-5 pt-6 pb-2.5 sm:px-7.5 xl:pb-1` (lệch trên dưới, đệm dưới chỉ có 4px/10px).
   - Thanh công cụ lọc (Filter bar) tách thành 1 card riêng với `p-4`, tách rời khỏi bảng dữ liệu khiến hai khối bị lệch lề.
   - Thẻ Dashboard dùng `p-5`, Login dùng `p-6 sm:p-8.5`.
2. **Bo góc (Border Radius) thô cứng**:
   - Sử dụng `rounded-sm` (2px) ở khắp các bề mặt cards, modals và bảng, tạo cảm giác giao diện sắc nhọn, cổ lỗ và chắp vá.
3. **Form Input và Icon lệch tâm trục dọc**:
   - Icon nằm trong input định vị bằng `top-3` thay vì căn giữa theo flexbox/inset-y, gây lệch tâm khi input thay đổi kích thước.
4. **Xung đột lồng ghép Padding tại Workspace**:
   - `<main>` layout đã có `p-4 md:p-6 lg:p-8`.
   - `.kanban-wrapper` lại nhồi thêm `padding: 16px` từ SCSS cũ.
   - Cột Kanban có `padding: 12px`, thẻ Task có margin riêng $\rightarrow$ Tạo ra 3-4 tầng padding lồng nhau làm nghẹt bảng Kanban.
5. **Lỗ hổng an toàn tài khoản SuperAdmin**:
   - `DeleteUserCommandHandler` chưa có guard clause chặn việc xóa SuperAdmin hoặc tự xóa chính mình, tạo nguy cơ Lockout toàn hệ thống.

## 2. Mục tiêu (Goals & Non-Goals)

### Goals
1. **Thiết lập Hệ thống Không gian 8px (8px Spatial Grid System)** nhất quán cho toàn bộ các trang.
2. **Chuẩn hóa Khung chứa (Container Scale)**:
   - Trang nội dung tiêu chuẩn (Dashboard, Users, Roles, Audit Logs): `max-w-7xl mx-auto w-full px-4 sm:px-6 lg:px-8 py-6` với nhịp điệu `space-y-6`.
   - Trang Workspace (Kanban & Chat): Chế độ Full-Height `h-[calc(100vh-4rem)] p-4 sm:p-6 flex flex-col` loại bỏ padding lồng ghép.
3. **Chuẩn hóa Bề mặt & Thẻ (Surfaces & Cards)**:
   - Bo góc hiện đại: Toàn bộ Cards, Modals, Tables chuyển sang `rounded-xl` (12px). Inputs và Buttons dùng `rounded-lg` (8px). Badges và Pills dùng `rounded-full`.
   - Hợp nhất Data Table: Gộp Search/Filter Toolbar và Table vào **1 Card duy nhất**:
     - Toolbar: `p-5 border-b border-stroke dark:border-strokedark`.
     - Header `<th>`: `py-3.5 px-6 font-semibold text-xs uppercase tracking-wider`.
     - Dòng dữ liệu `<td>`: `py-4 px-6 text-sm align-middle`.
     - Phân trang dưới đáy: `p-4 border-t border-stroke dark:border-strokedark`.
4. **Chuẩn hóa Form Ergonomics**:
   - Chiều cao input cố định: `h-11` (44px) với padding `px-4`.
   - Icon căn giữa hoàn hảo: `absolute inset-y-0 right-0 flex items-center pr-3.5 pointer-events-none`.
   - Label spacing: `mb-1.5 text-xs font-semibold block`.
5. **Dọn dẹp Workspace CSS Clashes**:
   - Viết lại Kanban columns sang CSS Grid/Flexbox Tailwind với cột cố định `w-80 shrink-0` và cuộn ngang `overflow-x-auto gap-5`.
   - Loại bỏ các quy tắc SCSS lồng padding/margin không cần thiết.
6. **Bảo vệ an toàn tài khoản SuperAdmin**:
   - Backend `DeleteUserCommandHandler`: Chặn tự xóa chính mình và chặn xóa user mang vai trò `SuperAdmin`.
   - Frontend: Ẩn/Disable nút xóa đối với SuperAdmin, hiển thị tooltip bảo vệ.

### Non-Goals
- Không thay đổi hợp đồng API hay database schema.
- Không tạo mock metrics / mock charts vô nghĩa trên Dashboard.
- Không phá vỡ các selectors của Playwright E2E tests (`.kanban-board-container`, `.chat-room`, `.dept-item`, `.channel-item`).

## 3. Quy chuẩn Chi tiết Hệ thống Không gian (Design Tokens)

| Thành phần | Token / Quy chuẩn | Giá trị CSS thực tế | Ghi chú |
| :--- | :--- | :--- | :--- |
| **Page Container** | `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-6` | Max 1280px, padding 16/24/32px | Dành cho Dashboard, System |
| **Workspace Container** | `h-[calc(100vh-4rem)] p-4 sm:p-6 flex flex-col` | Full height trừ header (64px) | Dành cho Kanban, Chat |
| **Card Surface** | `rounded-xl border border-stroke bg-white shadow-xs dark:border-strokedark dark:bg-boxdark` | 12px border radius | Không dùng `rounded-sm` |
| **Card Padding** | `p-6` | 24px đều cả 4 cạnh | Thay cho `px-5 pt-6 pb-2.5` |
| **Table Header Row** | `py-3.5 px-6` | 14px dọc, 24px ngang | Thống nhất toàn bộ bảng |
| **Table Body Row** | `py-4 px-6` | 16px dọc, 24px ngang | Hover mượt mà |
| **Input Height & Padding**| `h-11 px-4 py-2.5 rounded-lg` | 44px cao, 8px radius | Chuẩn công thái học ngón tay/chuột |
| **Input Icon** | `inset-y-0 right-0 flex items-center pr-3.5` | Căn giữa tuyệt đối trục Y | Triệt tiêu lỗi lệch tâm `top-3` |
| **Form Spacing** | `space-y-4` hoặc `space-y-5` | 16px - 20px | Nhịp điệu form chuẩn |
| **Button Height & Radius**| `h-10 px-4 rounded-lg font-medium text-sm` | 40px cao, 8px radius | Đồng bộ với input |

## 4. Kế hoạch Kiểm thử & Xác minh (Verification)

1. **Độ phân giải & Responsive**:
   - Desktop (1440px+): Nội dung nằm gọn gàng trong `max-w-7xl`, lề 2 bên đối xứng hoàn hảo.
   - Laptop / Tablet (768px - 1024px): Bảng dữ liệu cuộn ngang không vỡ layout, lề thu gọn `px-6`.
   - Mobile (< 768px): Drawer sidebar trượt mượt mà, lề `px-4`.
2. **Trực quan Form & Tables**:
   - Kiểm tra icon trong input Email & Password nằm chính giữa trục Y.
   - Kiểm tra bảng dữ liệu nằm trong 1 card duy nhất với viền mỏng và bo góc 12px.
3. **Workspace Kanban**:
   - Kiểm tra bảng Kanban không bị co quắp bởi padding lồng nhau.
4. **Unit Tests & Build**:
   - `npm test` frontend vượt qua 100% tests.
   - `dotnet test backend/AgentCoreSystem.slnx` vượt qua 100% tests.
